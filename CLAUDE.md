# Website Cabinet Mutsaard – medical practice, Laken (Brussels)

Public website of Cabinet Mutsaard, live at cabinetmutsaard.be.
React + Vite + Tailwind (originally generated by Lovable), hosted on Netlify (see netlify.toml).
The people editing this site are doctors, not developers: explain things in plain language and never ask them to run commands.

## Workflow rules
- Never push directly to main. Work on a new branch and open a pull request.
- Netlify posts a Deploy Preview link on every pull request; ask the editor to check it on laptop and phone before merging.
- In the pull request description, list in plain words what changed on which page.
- Make sure the site still builds (`npm ci` then `npm run build`) before opening the pull request.
- Keep the existing design: same fonts, colours, spacing and components. Reuse existing page layouts for new pages.
- Check that every change also looks good on mobile.
- Compress new images and give every image a descriptive alt text.
- Keep netlify.toml as it is (it holds the build settings and the page-routing rule).

## Content rules
- The site is trilingual: Dutch (nl), French (fr) and English (en). Every text change must be made in ALL three languages.
- Tone: calm, professional, medical. No hype.
- Belgian rules restrict advertising by doctors. Keep text factual and informative; no promotional language.
- Never invent medical information, opening hours, doctors' details or prices. Ask if information is missing.
